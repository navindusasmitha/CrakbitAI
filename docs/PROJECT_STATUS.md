# Crakbit AI — Project Status

**Last updated:** 2026-09-13

## Current Stage

**Early development / Security MVP preparation**

Crakbit AI currently has a public project identity, website, fundraising application, repository and initial technical documentation. The core security platform is not yet production-ready.

## Immediate Priorities

1. Establish clean repository documentation and contribution workflow.
2. Define normalized security finding schema.
3. Build the first deterministic scanner prototype.
4. Add Python and JavaScript/TypeScript security rules.
5. Add secret detection with safe redaction.
6. Build AI-assisted explanation/remediation on top of scanner evidence.
7. Publish a public MVP demo.
8. Begin CLI work after scanner core is stable.

## What Is Not Yet Production-Ready

The following should not be described as completed production features yet:

- Full AI security platform
- Production-grade scanner coverage
- Production API
- Production CLI
- Smart-contract security suite
- Dedicated blockchain network
- CRKBIT token/coin

## Evidence and Transparency

Crakbit AI aims to distinguish clearly between:

- completed work,
- active development,
- planned features, and
- long-term research.

This document should be updated as milestones are completed so donors, reviewers and contributors can see the project's real development state.
