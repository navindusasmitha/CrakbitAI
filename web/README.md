# Crakbit Web

This directory is reserved for the Crakbit AI public web application and website source.

Planned responsibilities:

- Public project information
- Security MVP interface
- Code scan submission workflows
- Findings and remediation display
- Funding/transparency links
- Documentation and project status

Security requirements include safe rendering, strict input validation, secure authentication where introduced, rate limiting and careful handling of source code and secrets.

The current public project website is available at:

https://crakbit.space
