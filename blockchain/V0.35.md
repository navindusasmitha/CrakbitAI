# Crakbit Chain v0.35 Alpha — Public PoW Testnet Evidence Gate

**Package:** `0.35.0a1`  
**Active devnet PoW:** `crakpow-scrypt-v1`  
**RandomX:** optional candidate only; not active consensus  
**P2P:** `crakbit-p2p/1`  
**Pool:** `crakbit-pool/2`  
**Status:** public-testnet evidence tooling — **not production mainnet**.

Production CRKBIT has not launched. There is no official presale or production token contract.

## Purpose

v0.35 moves the project from local/devnet preparation toward a real independently operated public PoW testnet campaign. The code does not fabricate deployment evidence: it provides signed formats, probes, convergence checks, duration gates, fault-campaign records and a freeze artifact that only becomes satisfiable when real external evidence exists.

## Host attestation

Each independent operator should use a dedicated evidence-signing key, not a wallet/mining/P2P private key:

```powershell
crakchain pow-host-v35-attest `
  --key private\operator-evidence.json `
  --operator-id operator-a `
  --node-id NODE_ID `
  --provider provider-a `
  --region region-a `
  --rpc-url https://node-a.example `
  --p2p-endpoint node-a.example:28444 `
  --source-commit <40-char-git-sha> `
  --chain-id crakbit-pow-testnet-v1 `
  --genesis-hash <64-hex-genesis> `
  --independently-managed `
  --miner-role `
  --output evidence\host-a.json
```

The signature proves the holder of the evidence key signed the statement. It does **not** independently prove ownership, provider, region, or operational independence.

## Live node probes

```powershell
crakchain pow-node-v35-probe `
  --rpc-url https://node-a.example `
  --output evidence\probe-a.json
```

Collect observations from 4+ independently managed nodes, then:

```powershell
crakchain pow-convergence-v35-check `
  --observation evidence\probe-a.json `
  --observation evidence\probe-b.json `
  --observation evidence\probe-c.json `
  --observation evidence\probe-d.json `
  --output evidence\convergence.json
```

## Soak gate

The soak summary uses recorded timestamps. It cannot turn a short run into a 24h/72h/7d pass.

```powershell
crakchain pow-soak-v35-summarize `
  --sample evidence\sample-start.json `
  --sample evidence\sample-end.json `
  --required-level 24h `
  --output evidence\soak-24h.json
```

Later campaigns should repeat with `72h` and `7d`.

## Fault / fork campaign

Only execute fault/load campaigns on infrastructure you own/administer or are explicitly authorized to test.

The v0.35 gate expects evidence for:

- restart,
- partition,
- reconnect,
- invalid block,
- invalid transaction,
- load,
- successful recovery,
- higher-work reorg observation,
- post-partition convergence.

Record completed campaign results:

```powershell
crakchain pow-fault-v35-record `
  --kind restart --kind partition --kind reconnect `
  --kind invalid-block --kind invalid-tx --kind load `
  --recovered `
  --higher-work-reorg-observed `
  --partition-convergence-observed `
  --invalid-work-rejected `
  --output evidence\fault-campaign.json
```

## Public-testnet gate

```powershell
crakchain pow-testnet-gate-v35-build `
  --key private\release-evidence.json `
  --host-attestation evidence\host-a.json `
  --host-attestation evidence\host-b.json `
  --host-attestation evidence\host-c.json `
  --host-attestation evidence\host-d.json `
  --convergence evidence\convergence.json `
  --soak evidence\soak-24h.json `
  --fault-campaign evidence\fault-campaign.json `
  --output evidence\public-testnet-gate.json
```

The gate requires unique operators, nodes and evidence signers, provider/region diversity, a single source/package/chain/genesis identity, convergence, soak duration, fault recovery, and multiple miner operators.

## Review freeze

After the gate is actually satisfied:

```powershell
crakchain pow-testnet-freeze-v35-build `
  --key private\release-evidence.json `
  --gate evidence\public-testnet-gate.json `
  --source-commit <exact-gated-sha> `
  --output evidence\public-testnet-freeze.json
```

This is a freeze for public-testnet review. It is **not** an independent security audit and it is **not** mainnet approval.
