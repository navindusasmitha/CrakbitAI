# Code of Conduct

## Our Commitment

Crakbit AI is committed to maintaining a respectful, constructive and inclusive environment for developers, researchers, students, security practitioners and contributors.

Participation in this project should be based on technical merit, evidence, responsible security practice and mutual respect.

## Expected Behavior

Examples of positive behavior include:

- Giving constructive technical feedback
- Respecting different experience levels
- Explaining security findings clearly and responsibly
- Accepting correction when evidence changes
- Keeping discussions focused on the project
- Crediting contributors and researchers fairly
- Protecting private or sensitive information
- Following responsible-disclosure practices

## Unacceptable Behavior

The following are not acceptable:

- Harassment, threats or targeted abuse
- Discrimination or degrading comments
- Publishing private information without permission
- Deliberately misleading security claims
- Sharing stolen credentials, private keys or personal data
- Encouraging unauthorized or destructive attacks through project channels
- Spam, scams, fake token promotions or impersonation
- Repeated disruption of technical discussions

## Security Research Conduct

Security discussions are welcome when they are intended for defensive, educational or authorized research purposes.

Do not publish sensitive vulnerability details before reasonable remediation coordination. Follow [`SECURITY.md`](SECURITY.md) for reporting security issues.

## Project Integrity

Contributors must not falsely claim that:

- Unreleased features are already production-ready
- CRKBIT has launched when it has not
- A token contract is official without an announcement from verified project channels
- Fundraising contributions guarantee financial returns
- Security testing was performed when it was not

Accuracy and transparency are core project values.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions or restrict participation when behavior repeatedly violates this policy.

Serious issues involving security, fraud, threats or privacy may be escalated to the relevant platform or authority where appropriate.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions and official community spaces managed by Crakbit AI.
